{% comment %} Header: the orange logo banner. Its own background is #F74F09, matched here so there is no seam if the image loads a pixel short. IMAGES-OFF FALLBACK, fixed after a real Gmail test (the email landed in Spam, where Gmail blocks all images). The first version zeroed this cell's font-size and line-height to kill the gap under the image -- which also crushed the alt text, collapsing the header to a thin strip with "Bancostore" chopped off and a broken-image icon. Now: - the cell has a real height and centres its content, so with no image it is still a proper orange banner; - the alt text is sized and styled as the wordmark, so it reads as a deliberate header rather than an error; - `display:block` on the image is what removes the gap below it, so the zeroed font metrics were never needed. {% endcomment %} {% comment %}Line items, POS style: the product name on its own line, then "qty x unit price" on the left with the line total on the right.{% endcomment %} {% comment %} Torn-paper edge. A row of characters rather than a CSS gradient: gradients and clip-path are unsupported in most email clients. It sits inside a table-layout:fixed table, and that is load-bearing. The line is nowrap so it clips instead of wrapping a stray dash onto a second line -- but in an ordinary auto-layout table a nowrap line sets the table's MINIMUM width, and a table will not shrink below that no matter what max-width says. Measured at a true 360px phone width, this one decorative line was forcing the whole receipt to 495px, pushing every price off the right edge of the screen. table-layout:fixed takes column width from the table rather than its content, so the line is clipped instead of widening everything around it. {% endcomment %}
